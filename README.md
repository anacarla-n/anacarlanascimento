# Digital Professional Showcase

PROMPT

Crie um portfólio web profissional, moderno, responsivo e visualmente elegante, utilizando todas as informações presentes no documento anexado (Currículo Lattes) como fonte principal de dados.

O objetivo é apresentar uma trajetória acadêmica e profissional sólida na área de Tecnologia da Informação, Engenharia de Software, Experiência do Usuário (UX), Interação Humano-Computador (IHC) e Desenvolvimento de Software Seguro.

Estrutura do Portfólio

1. Página Inicial (Hero Section)

 Nome completo em destaque.

 Foto profissional (caso disponível no currículo).

 Título profissional.

 Breve resumo da trajetória acadêmica e profissional.

 Botões para contato, currículo completo e LinkedIn (quando disponível).

2. Sobre Mim

 Apresentação pessoal e profissional.

 Formação acadêmica.

 Principais áreas de atuação.

 Valores, competências e contribuições para ensino, pesquisa e mercado.

3. Experiência Docente

Criar uma seção específica destacando a atuação como professora de graduação e pós-graduação.

Graduação em Engenharia de Software

Destacar experiência docente nas disciplinas:

 UX/UI (User Experience e User Interface)

 IHC (Interação Humano-Computador)

 Modelagem de Processos

 Modelagem de Sistemas

Pós-Graduação

Destacar experiência docente nas disciplinas:

 Desenvolvimento de Software Seguro

 UX/UI

 IXD (Interaction Design)

Apresentar:

 Instituições de ensino.

 Períodos de atuação.

 Disciplinas ministradas.

 Metodologias utilizadas.

 Resultados e contribuições acadêmicas.

4. Formação Acadêmica

 Graduação.

 Especializações.

 Mestrado.

 Doutorado.

 Cursos complementares.

 Certificações.

Organizar em formato de linha do tempo (timeline).

5. Pesquisa e Produção Científica

Extrair do Currículo Lattes:

 Artigos publicados.

 Trabalhos em eventos.

 Projetos de pesquisa.

 Orientações.

 Participações em grupos de pesquisa.

 Produção técnica.

Apresentar em formato organizado e pesquisável.

6. Projetos e Atuação Profissional

 Projetos relevantes.

 Consultorias.

 Desenvolvimento de sistemas.

 Projetos de UX Research, UX Design e Engenharia de Software.

 Estudos de caso quando houver informações disponíveis.

7. Competências e Especialidades

Criar visualização moderna com categorias:

Engenharia de Software

 Modelagem de Sistemas

 Modelagem de Processos

 Arquitetura de Software

 Desenvolvimento Seguro

Experiência do Usuário

 UX Research

 UX Design

 UI Design

 IXD

 Design Thinking

Ensino e Pesquisa

 Docência

 Orientação Acadêmica

 Produção Científica

 Metodologias Ativas

8. Premiações, Reconhecimentos e Participações

 Eventos científicos.

 Bancas.

 Comissões.

 Premiações.

 Certificações relevantes.

9. Contato

 E-mail.

 LinkedIn.

 Lattes.

 Redes profissionais disponíveis.

Diretrizes de Design

 Design premium e institucional.

 Visual moderno inspirado em portfólios acadêmicos internacionais.

 Interface clean com foco em legibilidade.

 Paleta sofisticada (azul marinho, branco, cinza claro e detalhes em dourado suave).

 Componentes responsivos.

 Animações discretas e elegantes.

 Modo claro e escuro.

 SEO otimizado.

 Acessibilidade WCAG.

 Layout compatível com desktop, tablet e smartphone.

Tecnologias Sugeridas

 React + Next.js

 TypeScript

 Tailwind CSS

 Framer Motion

 Ícones Lucide

 Componentes modernos e acessíveis

Requisitos Importantes

 Utilizar exclusivamente as informações presentes no Currículo Lattes anexado.

 Não inventar experiências ou formações.

 Organizar os dados de forma estratégica para fortalecer a marca profissional da docente.

 Destacar a expertise em Engenharia de Software, UX/UI, IHC, Modelagem de Sistemas, Modelagem de Processos, Desenvolvimento de Software Seguro e IXD.

 Produzir um resultado visual de alto padrão, adequado para seleção acadêmica, consultorias, projetos de pesquisa e oportunidades profissionais.
